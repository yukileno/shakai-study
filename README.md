# 小学校社会科 定着＆記述マスター

4択クイズ（再認）から一歩進み、**テストで確実に点が取れる記憶の定着**と**記述問題が自分の力で書けるようになること**を目指した、学習科学に基づく小学校社会科Webアプリです。

## 特長（完全無料・外部API不使用）
1. **Step 1：じっくり4択クイズ（基礎・再認）**
   - スピード勝負による当てずっぽうを防ぎ、解答直後に「重要キーワード」と「解説」を確認できます。
   - 間違えた問題だけをその場で解き直す機能つき。
2. **Step 2：語句ブロック並び替えパズル（構造化・足場かけ）**
   - 白紙だと書けない記述問題を、4つの語句ブロックをタップして並び替えることで、「原因・目的 ➔ 工夫 ➔ 〜ため。」の文構造を自然に習得できます。
3. **Step 3：キーワード指定 1行記述チャレンジ（再生・自己説明）**
   - 2つのキーワードを使って1行記述に挑戦します。
   - **🎤 音声入力（Web Speech API）** と **⌨️ タイピング入力** の両方に対応。
   - 入力中にキーワードや文末（「〜ため。」等）が入るとリアルタイムで `✅ OK` が点灯し、漢字・ひらがなの表記ゆれに対応したJavaScript採点ロジックで即座にアドバイスを表示します。
4. **🔊 音声読み上げ ＆ 📖 重要まとめカード**
   - ブラウザ標準の音声合成機能（`speechSynthesis`）により、解説や模範解答を耳から聞いて音読練習ができます。

## 使い方
- `index.html` をブラウザ（Chrome / Edge / Safari 等）で直接開くだけで動作します（インターネット上の有料API通信やサーバー費用は一切かかりません）。
